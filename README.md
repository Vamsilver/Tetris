# Консольная игра «Тетрис»

Учебный проект на C#, выполненный по кейс-задаче № 4. Фигуры представлены матрицами из `0` и `1`, игровое поле — матрицей 10×20 клеток.

## Возможности

- семь классических фигур;
- движение влево и вправо;
- вращение на 90 градусов;
- ускоренное падение;
- удаление заполненных линий и подсчёт очков;
- обнаружение конца игры;
- перезапуск после проигрыша.

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Перемещение фигуры |
| ↑ | Поворот фигуры |
| ↓ | Ускорить падение |
| Esc | Завершить игру |
| R | Начать заново после окончания игры |

## Запуск

Откройте файл `Tetris.sln` в Visual Studio 2022 и нажмите `F5` либо выполните в терминале:

```bash
dotnet run
```
