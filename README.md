# Консольная игра «Тетрис»

Учебный проект на C#, выполненный по кейс-задаче № 4. Фигуры представлены матрицами из `0` и `1`, игровое поле — матрицей 10×20 клеток.

## Возможности

- семь классических фигур;
- движение влево и вправо;
- вращение на 90 градусов;
- ускоренное падение;
- мгновенное падение по пробелу;
- поворот возле стен и пола;
- удаление заполненных линий и подсчёт очков;
- уровни с постепенным увеличением скорости;
- предпросмотр следующей фигуры;
- обнаружение конца игры;
- перезапуск после проигрыша.

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Перемещение фигуры |
| ↑ | Поворот фигуры |
| ↓ | Ускорить падение |
| Пробел | Мгновенно опустить фигуру |
| Esc | Завершить игру |
| R | Начать заново после окончания игры |

## Запуск

Откройте файл `Tetris.sln` в Visual Studio 2022 и нажмите `F5` либо выполните в терминале:

```bash
dotnet run
```

## Структура проекта

- `Tetromino.cs` — падающая фигура, её матрица, тип и вращение;
- `TetrominoType.cs` — понятные названия семи классических фигур;
- `GameField.cs` — матрица поля, проверка столкновений, очистка линий и отрисовка;
- `TetrisGame.cs` — управление фигурами, игровой цикл, уровни и проверка конца игры;
- `Program.cs` — запуск приложения, сообщение о проигрыше и перезапуск;
- `Tetris.sln` — решение для открытия проекта в Visual Studio 2022.
